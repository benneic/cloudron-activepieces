## First steps

1. Open your app URL in a browser. **The first user to sign up becomes the platform admin.**
2. Use **Platform settings** to configure email (if you did not enable the Sendmail addon, set SMTP there or via environment variables on the app).
3. For enterprise SSO (SAML, etc.), see the [Activepieces admin docs](https://www.activepieces.com/docs/admin-guide).

## Data

- Database and Redis are managed by Cloudron and included in app backups.
- The **local storage** directory holds cache and generated secrets; keep backups enabled for this app.
